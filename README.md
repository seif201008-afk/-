# 📋 مشاكل الفريق

موقع بسيط وعصري (عربي، من اليمين للشمال، ومتظبط على الموبايل) الفريق كله يسجّل فيه المشاكل.

## المميزات
- **فورم إضافة مشكلة:** المشكلة (إجباري) · ملاحظة (اختياري) · اسمك من قائمة منسدلة (إجباري) · تصنيف (بوت / داشبورد / تاني).
- **التاريخ والوقت بيتسجلوا تلقائي**، محدش بيكتبهم.
- **حالة المشكلة:** مفتوحة أو اتحلت، وبتتغير بزرار واحد.
- **فلترة وبحث:** تابات (مفتوحة / اتحلت / الكل) مع العدد، وبحث، وفلتر بالتصنيف.
- **تحديث لحظي:** أي حد يضيف مشكلة، تظهر عند الباقيين على طول من غير ريفريش.
- **باسورد بسيط للفريق (اختياري)** عشان لو اللينك اتسرب.
- **وضع تجربة:** لو لسه ما حطيتش بيانات Supabase، الموقع بيشتغل عادي والبيانات بتتحفظ على جهازك بس.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة |
| `style.css` | التصميم |
| `app.js` | المنطق |
| `config.js` | **الإعدادات، الملف الوحيد اللي هتعدّل فيه** |
| `supabase.sql` | كود الجدول في Supabase |

## التشغيل (3 خطوات)

### 1) اعمل الجدول في Supabase
افتح مشروعك في Supabase ← **SQL Editor** ← الصق محتوى `supabase.sql` ← **Run**.
ده بيعمل جدول جديد اسمه `team_issues`، منفصل خالص عن جداول المطاعم.

### 2) عدّل `config.js`
- `SUPABASE_URL` و `SUPABASE_ANON_KEY`: هتلاقيهم في Supabase ← **Project Settings ← API**
  (استخدم مفتاح **anon / public**، وأوعى تحط مفتاح `service_role`).
- `TEAM_NAMES`: أسماء الفريق.
- `CATEGORIES`: التصنيفات.
- `TEAM_PASSWORD`: باسورد الفريق، أو سيبه `""` من غير باسورد.

### 3) ارفع الموقع
أسهل طريقة: **GitHub Pages**
Settings ← Pages ← Source: `Deploy from a branch` ← اختار الفرع والفولدر `/ (root)` ← Save.
هيطلعلك لينك تبعته للفريق.

(أو اسحب الفولدر كله على [Netlify Drop](https://app.netlify.com/drop).)

للتجربة على جهازك: افتح `index.html` في المتصفح على طول.

## ملحوظة عن الأمان
الباسورد ومفتاح anon موجودين في كود الصفحة، يعني حد فاهم ممكن يشوفهم. ده كفاية لأداة داخلية للفريق،
بس ماتحطش في الجدول ده بيانات حساسة زي بيانات العملاء.
